# Identity

Canonical public organization identity for `0xda-market`.

## Canonical identity

- **type:** organization
- **id:** `0xda-market`
- **display name:** `0xda-market`
- **GitHub namespace:** `github.com/0xda-market`

The machine-readable source is [`identity.yaml`](identity.yaml). Its type and id must match `manifest.yaml -> mind.subject` exactly.

The identity remains provider-independent even though the current GitHub namespace uses the same string. Equality with a provider login is not evidence or authority for the canonical id.

This initial Mind Protocol 0.9 canary does not publish a canonical visual mark. Provider avatars and presentation fallbacks are noncanonical unless explicitly adopted in a later named visual-identity rollout.

## Scope

This module owns only durable identity facts for the organization. Parent/child ecosystem relationships, provider bindings, products, projects, and runtime configuration require their own explicit contracts and are not inferred here.
